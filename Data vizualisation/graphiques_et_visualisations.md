# Guide des Visualisations de Données

Voici un tableau récapitulatif des principaux types de graphiques avec leurs représentations schématiques et leurs usages principaux.

| Nom                                                 | Graphique (Schéma)                                                                                                                                                                                               | Description & Usage                                                                                                                     |
| :-------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- |
| **Histogramme**                               | ![Histogramme - Les fiches CPGE](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRSh24gacsB2BRIrD6hE_316G21HezSJecavfxxSy_Q9A&s=10)                                                                         | Représente la **distribution d'une variable continue** en regroupant les données par intervalles (bins).                        |
| **KDE** *(Kernel Density Estimate)*         | ![How to visualize a kernel density estimate - The DO Loop](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcS52-tGTg6sq9A-GlBgtR61Q71kIhK3-sPxq6RG7FVUow&s=10)                                              | Estimation par noyau de la densité : une **courbe lisse** représentant la distribution de probabilité d'une variable continue. |
| **Boxplot** *(Boîte à moustaches)*        | ![Boîte à moustaches (Box Plot)](https://numiqo.fr/assets/tutorial/diagramme_en_bo%C3%AEte.png)                                                                                                                 | (Moustache max)  ┌─┴─┐       (3ème quartile / Q3)  │ ┼ │       (Médiane)  └─┬─┘       (1er quartile / Q1)                |
| **Barplot** *(Graphique en tuyaux d'orgue)* | ![Graphique tuyau d'orgue + empilé](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQPie6cvpSRChHXjdep25PNaNoDiCD2Wx59aC7mcVwtMXzmAGntOts37wA&s=10)                                                        | Compare des **valeurs agrégées** (ex: moyenne, somme) pour différentes catégories.                                            |
| **Countplot**                                 | ![seaborn.countplot — seaborn 0.13.2 documentation](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcT20RN4914U11vbx18-a8r-wvpWWi2cB_cX_2Vt1IAvdJy3ABqkTbU3TdN0&s=10)                                       | Affiche l'**effectif (nombre d'occurrences)** direct de chaque catégorie.                                                        |
| **Nuage de points** *(Scatter plot)*        | ![Construire un nuage de points grandiose avec Python - Stat4decision](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTmSwB3N7YPfPXhp05pQr1hXq6tTV36iuQ8y5rthGO3DQ&s=10)                                   | Montre la **relation ou corrélation** entre deux variables numériques.                                                          |
| **Courbe** *(Line plot)*                    | ![How can I create a chart on the dashboard with multiple lines showing  trends? - Smartsheet Community](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQpFLCY2yMonm6H_c1CX8F9UI5TAiHKVYfHeovZN7_Diw&s=10) | Évolution d'une variable continue au fil du temps (séries temporelles).                                                               |
| **Heatmap** *(Carte thermique)*             | ![1793341744956](image/graphiques_et_visualisations/1793341744956.png)                                                                                                                                            | Matrice colorée montrant l'**intensité des valeurs** ou les **correlations** entre variables.                             |
| **Pairplot** *(Matrice de croisement)*      | ![seaborn.pairplot — seaborn 0.13.2 documentation](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRvrVfUJbMpGAmqSiQA_9h0Pqx5m5pafYCsKkuOwasyiwkaArSEYvupF9Ns&s=10)                                        | Grille de graphiques croisant **toutes les variables d'un jeu de données** deux à deux.                                         |
| **Camembert** *(Pie chart)*                 | ![1793341914378](image/graphiques_et_visualisations/1793341914378.png)                                                                                                                                            | Proportion des différentes parties d'un tout (en pourcentages).                                                                        |
